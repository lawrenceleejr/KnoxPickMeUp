# Knox Pick-Me-Up — Pilot Print RFQ

Everything to request from a print shop to run a **1-year pilot with 3 bars
and 3 coffee shops** (6 venues), sized so the resulting quote can go straight
into the city's pilot budget as the printing line. Written against the
[Graphic Creations quote form](https://www.graphiccreations.com/quote/)
(Knoxville — on-theme per [PRINTING.md §3](PRINTING.md): a local shop is the
best fit and a natural "printing donated by" sponsor), but the item list works
for any commercial printer.

General specs that apply to every line: artwork is **supplied print-ready** —
vector PDFs at exact trim size with all type outlined (see
[PRINTING.md §4](PRINTING.md)); edge-bleed pieces get 1/8″ bleed added to the
shop's template before the final run. Samples of every piece are public at
**[knoxpickmeup.org/materials](https://knoxpickmeup.org/materials/)**.

coasters ≈ $0.08–0.15 ea → $1,200–2,300; everything else is small runs, roughly
$800–1,600 combined. Expect the whole kit to land **~$3,000–5,000** — in line
with the pilot budget's printing line in [PROGRAM.md §4](PROGRAM.md). Put the
itemized quote, not the ballpark, in front of the city.

## 4. Before production (not needed for the quote)

The quote can go out on the sample artwork as-is. Before an actual run:

1. Regenerate cards with the **real program key** and the next serial range,
   coasters/signage with the **final venue roster** and QR targets, and
   register QRs per shop — [PRINTING.md §4–5](PRINTING.md).
2. Get the shop's bleed/crop template and extend the generators to it
   (parametric — a small change).
3. Run the full pre-flight checklist in [PRINTING.md §6](PRINTING.md):
   serial continuity, key match, pack check-out proof, end-to-end card scan,
   ballpoint pen test on the actual stock, QR size sanity.
